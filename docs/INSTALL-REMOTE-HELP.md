# How to set up remote help on the POS laptop

This lets Silong Strategies fix your POS laptop from far away. It takes about
5 minutes for each laptop. You do not need to sign in to anything.

**Need help? Call or text <HELP-CONTACT>.**

## What this does

This tool lets Silong Strategies see the laptop screen, run fixes, and copy
files. We only use it to support Aronium and the sync tool. The connection is
private and locked with a password. You can remove it at any time: open
**Settings → Apps → Installed apps**, find **Mesh Agent**, click **...**, then
**Uninstall**.

## Steps (laptop 1)

1. Plug the laptop into power.
2. Open the internet browser (Chrome or Edge).
3. Type this address and press **Enter**: **<INVITE-LINK>**
4. Click the **Windows** download button. A file starts to download.
5. When it finishes, click the file at the top or bottom of the browser.
6. If a blue box says **"Windows protected your PC"**, click **More info**, then click **Run anyway**.
7. A box asks **"Do you want to allow this app to make changes?"** Click **Yes**.
   If it asks for a password instead, stop and call us.
8. A small window opens. Click **Install**. Do **not** click Connect.
9. Wait until it says the install is done (under a minute). Close the window.

## Check that it worked

10. Open **Settings → Apps → Installed apps**. You should see **Mesh Agent** in the list.
11. Call or text us: "Laptop 1 is done." We will check that we can see it.

## Laptop 2

12. Do steps 1 to 11 again on the second laptop. Tell us "Laptop 2 is done."

## Every day

- Keep both laptops **plugged in**.
- Do **not shut them down** at night. Letting the screen go dark is fine.
- If we can't reach a laptop, we will call you to check that it is on.
